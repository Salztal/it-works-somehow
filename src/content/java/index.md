# Javaから、データが残るアプリへ。

入力したタスクが、アプリを閉じてもDBに残る。その仕組みを、小さな変更と動作確認を重ねて学びます。

## この教材の進め方

まずコンソール版の**Todo**を作り、次に同じ役割分担を使ってWeb版の**TodoJSP**へ進みます。Java 17・MySQL 8.0.20・Tomcat 9が基準です。授業の時間に合わせて、1章を複数回に分けて構いません。

1. 最初に[環境構築](setup.md)を読み、JavaとMySQLを別々に動かします。
2. 第1〜3章で、入力・メニュー・DTOを練習します。
3. 第4〜7章で、SQLとコンソール版のDB連携を作ります。
4. 第8〜10章で、ブラウザの入力と表示へ置き換えます。

各章は「ゴール→思い出す→一緒に実装→小課題→確認」の順です。分からなくなったら、現在のファイル名と、最後に成功した確認まで戻りましょう。

## 完成するもの

| 操作 | コンソール版 | Web版 |
|---|---|---|
| 入力 | キーボードから1行ずつ | HTMLフォーム |
| 表示 | 標準出力 | JSP |
| 受付 | Main | Servlet |
| DBへ渡す | Service → DAO | Service → DAO |
| 保存先 | MySQLのtasksテーブル | 同じtasksテーブル |

必須課題は登録・一覧・更新・単件削除です。全件削除は追加課題として扱います。

## 迷ったときの入口
