# 追加課題：全件削除と使いやすさ

## ゴール

必須のCRUDが動いた後に、対象件数を示して全件削除を実行できます。通常の単件削除との違いを説明します。

## 実装の方針

完成版には実装例があります。まず自分で考える場合は、DAOの`deleteAll`、Serviceの`deleteAllService`、コンソールの`deleteAllTodo`、Webの`DeleteAllServlet`を順に読みます。

1. 実行前の件数を一覧取得の結果から数える。
2. 全件が対象であることを説明する。
3. コンソールとWebの両方で、`DELETE ALL`の完全一致で実行する。
4. SQLの結果から実際に削除した件数を表示する。

確認画面を開いてから実行するまでに他の操作で件数が変わる場合があります。表示する削除結果には、実行前の予定件数ではなくSQLの戻り値を使います。

## 小課題

- 間違った確認文字列では削除されないことを確認する。
- 0件のときに実行した場合、0件削除と表示されることを確認する。
- WebのGETで確認画面を開くだけでは消えないことを確認する。

## さらに考える

登録後の案内、入力欄のラベル、一覧の並び順を改善するとしたら何を変えますか。新しい機能を増やす前に、変えたい動作と確認方法を書いてから実装しましょう。

この教材の全件削除は、自分のローカルの学習用DBに対してのみ使います。
