## 設計判断

- サイト用ナビゲーションのdisclosureとしてnative details/summaryを利用。ARIA menuの独自キー操作やフォーカストラップを導入しない。JSなしでも全8カテゴリへ進める。JSではEscape、外側クリック、メニュー外へのフォーカス移動で閉じる。
- 分野名・URLは既存catalogのカテゴリ入口から取得。グループ、短い紹介、既存の入口リンクだけをUIメタデータとしてまとめ、ヘッダー・TOP・フッターで共有する。
- 目的別は「仕組みから学ぶ」「動かして理解する」「困りごとから調べる」。Javaの配布コードはブラウザ内模型と誤認させず、既存ダウンロードへの入口として示す。
- 講義本文、問題、索引、保存キー、version 1とバックアップ仕様、既存のURL/アンカーを保持する。新しい教材やカテゴリ・依存ライブラリを追加しない。
