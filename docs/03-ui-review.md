# UI検収記録

実施日: 2026-11-10 (Asia/Tokyo)。Chromium系のアプリ内ブラウザでローカル静的ビルドを確認しました。CSS幅はDOMの`innerWidth`で確認しています。

## 設計方針と確認結果

- 暖白の背景、墨色の本文、深い青緑の操作色。Javaの入口に茶色を補助的に使用。グラデーションや発光、ガラス風装飾、広告風画像は使用していません。
- トップは教材選択、学習再開、目的別入口、検索を順に配置。タイトル・ラベルは内容が分かる日本語へ整理しました。
- PCは固定ヘッダー、左の章目次、読みやすい本文幅、広い画面では右のページ内目次。スマホは章目次を折りたたみ、本文を1列で表示します。
- 320 / 390 / 768 / 1440 CSS pxで代表ページを検査。画面全体の横はみ出しはありません。384 / 922 / 1200 pxでも補足確認しました。
- 320・768px: ホーム、Javaフォーム登録、IP・サブネット。
- 390px: 上記に加え、Azure構成、ミッション、Java環境構築、ダウンロード、検索、学習記録。
- スマホの目次開閉から第6章への移動、パンくず、前後の章への導線を確認しました。
- Javaのコード表示とコピーボタンを確認。第5章は5つのコードブロックに5つのコピーボタンがあり、コピー成功の表示を確認しました。
- 表・コードは各領域内でスクロールでき、本文幅を押し広げません。図はスマホ幅に収まり、ラベルと接続関係を表示します。
- スキップリンク、フォームのラベル、問題のfieldset/legend、状態通知、フォーカス表示、押下状態、動きの軽減設定を実装。スマホの検索アイコンにもアクセシブル名を付けました。
