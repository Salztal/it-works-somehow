## 既知の制約

- モデルはファイル単位の3方向比較。実Gitの行単位マージ・rename・バイナリ・複数merge base・サブモジュール・空/重複コミット等を完全に再現しない。
- 複雑なsquash競合はモデルで拒否し、G08の説明へ誘導。オンラインのGitHub機能とCLI操作は教材で分ける。
- reflogは教材のメモリー内履歴。保持期限・オブジェクト削除は再現せず本文で限界を示す。未コミット編集の復旧保証はない。
- シミュレーターのやり直しはメモリー状態だけを初期化し、学習記録の保存・削除機能へ接続しない。
- サイトは既存の静的アセット/検索索引取得以外の外部通信、アクセス解析、新依存パッケージを追加していない。
