## 後継・更新・版に関する判断

| 対象 | 確認結果と教材への反映 |
|---|---|
| TLS 1.3 | [RFC 9846](https://www.rfc-editor.org/info/rfc9846/)（2026-07）が8446の後継。鍵交換/認証/AEAD、KeyShare再利用禁止、使用上限、0-RTTのリプレイ制約を区別 |
| TLSの運用指針 | RFC9325には9852/10015による更新。古いTLS1.2のRSA等の鍵交換を現在の推奨として教えていない。TLS1.3の有限体DHまで一括禁止とはしていない |
| X.509 | RFC5280は後続更新6818/8398/8399/9549/9598/9608/9618/9925/10007あり。パス検証の基本を扱い、全拡張を独自実装する教材ではない |
| TLSサービス識別 | [RFC9525](https://www.rfc-editor.org/info/rfc9525/)が6125を廃止。DNS名はSAN dNSName、Common Nameフォールバックを教えない |
| OCSP | RFC6960を8954/9654が更新。goodの保証範囲、応答者権限/鮮度、問い合わせ不能時の方針を区別 |
| OAuth | RFC6749に対し現行安全指針[RFC9700](https://www.rfc-editor.org/info/rfc9700/)を参照。認可とOIDCの認証を分離。PKCE/state/nonceの条件を一律必須と混同しない |
| OIDC | Core 1.0 errata set 2（2023-12-15）。audience/issuer/期限、nonceを送った場合の一致検査 |
| SMTP | RFC5321は7504で更新、STARTTLS RFC3207は7817で更新。ホップごとのTLSと端末間保護を分離 |
| SPF/DKIM | RFC7208更新7372/8553/8616。RFC6376更新8301/8463/8553/8616。表示From認証や本文安全性と混同しない |
| DMARC | [RFC9989](https://www.rfc-editor.org/info/rfc9989/)（2026-05）が7489/9091を廃止。集約/失敗報告は9990/9991。DNS Tree Walkを単純な末尾2ラベル一致に置き換えず、デモはstrict完全一致限定 |
| DNSSEC | 4033/4034/4035には後続更新あり。9904が8624を廃止し、アルゴリズム推奨状態はIANAレジストリで確認。9905のSHA-1署名非推奨化/新規作成禁止、9824の不存在証明更新も参照 |
| PQC | FIPS203/204/205は2024-08-13 Final。203ページの2025-11-17、204ページの2026-07-31 potential errataも記録。SP800-227 Final（2025-09）を補足。候補選定や草案を標準化済み方式と混同しない |
| パスワード/認証 | NIST SP800-63B-4（2025-07 Final）、OWASP。パスキーの利用者検証条件、同期型と機器固定の違いを記述 |
| インシデント | NIST SP800-61 Rev.3（2025-04）がRev.2を置換。800-86/92の基本的な保全・ログ管理も参照し、古い版の段階図を現行版そのものとはしていない |
| FW/IDS/IPS | SP800-41 Rev.1（2009）/800-94（2007）。800-94 Rev.1の2012草案はFinal化されずretired。草案を現行版として採用していない |
| 暗号リスト | [CRYPTREC](https://www.cryptrec.go.jp/list.html) LS-0001-2022R2（2026-03-30）。古い方式名を新規設計向け推奨と混同しない |

## URL確認の制約と代替資料

- レッスンに掲げた一次資料はWeb取得と内容照合を行った。将来のリンク可用性は保証しない。RFC9904のinfoページで一時的な429があったため、取得できたRFC Editorの本文URLを掲載した。
- CISAのcanonical KEVページは取得環境で403になった。本文根拠は取得できた[CISA公式ミラー](https://github.com/cisagov/kev-data)へ変更した。canonical本文を取得確認済みとはしていない。
- CVE.orgのページはJavaScript必須の殻だけが返ったため、取得できた[公式CVE List](https://github.com/CVEProject/cvelistV5)を掲載した。
- IPA「10大脅威2026」は2026-01-29公開、主に2025年の事象を対象。発行年を発生年に読み替えていない。大量の統計や順位表は転載していない。
- PCAPは独自生成。X25519の公開値だけはRFC7748 §6.1の公開テスト値を利用し、私有鍵は収録しない。暗号化本文は合成バイト列で有効なAEADではない。RFC8448は旧8446時代の接続例として位置付け、現行仕様9846とは区別する。

各URLと利用レッスンの完全な一覧は4つの原稿JSONの `references` を参照。ビルド検査は書誌情報の必須項目・HTTPS URL・確認日の存在と公開HTMLへの反映を検査し、毎ビルド外部サイトへのネットワーク要求は行わない。
