Windows 11、Eclipse Temurin JDK 17.0.20.1+1、MySQL Community Server 8.0.20、Connector/J 8.0.33、Tomcat 9.0.118、JSTL API 1.2.1／実装1.2.5。

作業フォルダー内の独立したMySQLとTomcatを使用。DB名は`java_course_verify`、専用ポートはDB 33308／Web 38080。受講者用の接続例は3306／8080であり、実際の検証設定は公開しない。

## 再実行

Java・DB・HTTPの再実行手順は[verification/README.md](verification/README.md)を参照する。DBを使う検証はデータを削除するため、指定の使い捨てDBだけで実行する。

サイトと配布物の生成・確認：

```powershell
node scripts/package.mjs
node scripts/check.mjs
```

演習到達コードのDB検証を含める場合は、両版のローカル設定を検証用DBへ向けてから、以下を実行する。

```powershell
node scripts/check-exercises.mjs -JavaHome C:/tools/jdk-17 -TomcatHome C:/tools/apache-tomcat-9.0.118 -WithDatabase
```
