# 2. メニューを繰り返す

## ゴール

1で入力処理を実行し、6で終了できます。文字や範囲外の番号を入力しても、メニューへ戻れます。

## 思い出す

- 入力した文字列は`String`に入ります。
- 処理を分けるには条件分岐、繰り返すにはループを使います。
- Javaの文字列の内容を比べるときは`equals`を使います。

## 開始コード

[第2章開始ZIP](assets/downloads/02-menu-start.zip)の`Main.java`を開きます。前章の入力処理は`inputTask(scanner)`メソッドとして用意されています。

まず`try`ブロックの中へ、次の形を作ります。

```java
while (true) {
    System.out.println("1:入力  6:終了");
    String number = scanner.nextLine();
    if (number.equals("6")) {
        System.out.println("終了します。");
        return;
    }
    if (number.equals("1")) {
        inputTask(scanner);
    } else {
        System.out.println("1または6を選択してください。");
    }
}
```

`while (true)`は終了条件に到達するまで繰り返します。ここでは`return`が`main`メソッドを終了させます。`inputTask`へ渡す`scanner`は、前章と同じ入力の道具です。

## 一緒に確かめる

1. 1を選び、タイトルと詳細を入力する。
2. 再びメニューが出ることを確認する。
3. `abc`、`9`を入力し、案内が出ることを確認する。
4. 6で終了する。

今回は番号も文字列として受け取ります。`Integer.parseInt`による整数への変換は、第7章のID入力で学びます。

## 小課題

2を入力したとき、`一覧表示はこれから実装します。`と表示する分岐を追加してください。

### ヒント1

今は1かそれ以外の2通りです。1、2、それ以外の3通りへ分けます。

### ヒント2

`else if (number.equals("2"))`を、最後の`else`の前へ追加します。

## 完成条件

1→2→abc→6の順に操作して、途中で終了せず、6で終了できます。

## 完成版へのつながり

完成版では分岐を`switch`で記述しています。`case "1"`の処理が終わったら`break`でswitchを抜けます。ループ自体は続くので、再びメニューが表示されます。

`break`と`return`が抜ける範囲を、実際のコードを指しながら説明してみましょう。
