# 検証結果

## 検証環境

2026年10月19日〜20日に、Windows 11上の独立した学習用環境で確認しました。

| 項目 | 使用した版 |
|---|---|
| Java | Eclipse Temurin 17.0.20.1+1 |
| MySQL | Community Server 8.0.20 |
| Connector/J | 8.0.33 |
| Tomcat | 9.0.118 |
| JSTL | API 1.2.1／実装1.2.5 |

検証用DBは`java_course_verify`で、既存の学習用DBとは分けています。受講者用設定の3306ではなく、検証時は専用のローカルポートを使用しました。

## アプリの確認

- 両版をJava 17でコンパイルした。
- 両版のService・DAOについて各28項目のDB連携検証を実行した。
- 日本語・途中の空白・詳細の省略・上限文字数・不正な入力・存在しないIDを確認した。
- 同じ値での更新、単件削除、全件削除、接続を共有しないことを確認した。
- コンソールでメニューの範囲外、文字のID、再入力、正常登録、一覧、終了を確認した。
- Tomcat上で全JSPを実行し、HTTPによる32項目のフォーム検証を実行した。
- Webで登録・更新・削除、入力保持、リダイレクト、HTMLエスケープ、GETで削除しないことを確認した。
- DB接続失敗時に成功表示せず、Webで空の一覧と区別して入力を保持することを確認した。

## 公開資料と配布物

- 演習開始コード9個すべてをJava 17でコンパイルした。
- 講義どおりの到達コード9個もコンパイルし、基礎3課題を実行、DB5課題は各28項目のCRUDを確認した。
- 開始コード・完成版・SQL設定の11ZIPについて、内容とSHA-256を確認した。
- サイト内のリンク・アンカーと、公開対象外の設定ファイルなどが混入していないことを確認した。
- リポジトリ名付きURLを模したローカルHTTP配信で、全HTML・ZIP・CSS／JSの32ファイルを取得し、原本との一致を確認した。
- 狭い画面で、目次の開閉・検索・章移動・確認済みマークをブラウザから操作した。
- 公開用ZIPを別フォルダーへ展開し、元の非公開設定を使わずにサイト・配布物・両アプリを再ビルドした。
