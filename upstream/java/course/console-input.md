# 1. 入力した文字を表示する

## ゴール

タイトルと詳細を1行ずつ入力し、そのまま画面に表示できます。まだDBには保存しません。

## 思い出す

1. 文字列を入れる型は何ですか。
2. `System.out.println`の括弧の中には何を書きますか。

`String`は文字列の型です。変数は値に名前を付けて使うためのものです。まず「入力→変数→表示」という短い流れを確認します。

## 開始コード

[第1章開始ZIP](assets/downloads/01-input-start.zip)を展開し、`Todo/com.todo/main/Main.java`を開きます。実行すると案内だけが出ます。`main`メソッドの中を、次のコードへ置き換えます。

```java
try (Scanner scanner = new Scanner(System.in)) {
    System.out.print("タイトル：");
    String title = scanner.nextLine();
    System.out.println("入力したタイトル：" + title);
}
```

ファイル先頭の`package main;`と`import java.util.Scanner;`、クラス宣言は残します。`Scanner`はキーボードからの入力を読む道具です。`nextLine()`は改行までの1行を読みます。`try`の括弧は、この道具を使い終わったら閉じるための書き方です。詳しくは第5章で学びます。

## 一緒に確かめる

1. 実行して、`Java の 復習`と入力します。
2. 途中の空白も含めて表示されるか確認します。
3. `title`を`taskTitle`へ変えるなら、宣言と使用箇所の両方を変えます。

```text
タイトル：Java の 復習
入力したタイトル：Java の 復習
```

この実行例で、コロンの右側の最初の行は自分が入力する部分です。

## 小課題

タイトルの入力の後に、詳細の入力を追加してください。変数名は`detail`、出力は`入力した詳細：`とします。詳細でEnterだけを押した場合も試します。

### ヒント1：考え方

タイトルと同じく、案内→読み取り→表示の3つを並べます。

### ヒント2：使う文

`String detail = scanner.nextLine();`で詳細を受け取れます。同じ`scanner`を使います。

## 完成条件

- タイトルと詳細を順番に入力できる。
- 空白を含む文字列が途中で切れない。
- 詳細が空でも終了する。

## 最後に説明する

入力内容は、どの変数に入っていますか。プログラムを閉じた後にもその値は残るでしょうか。今回はDBに保存していないので、再実行しても前の値は復元されません。
